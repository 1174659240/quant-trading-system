## 0. 一句话

**选股与红利低波策略逐位相同**（同一份 weights 矩阵），唯一区别是**不再逐日把权重拉回目标**，只在 132 个调仓日成交。样本内累计 79.54% → **106.44%**（+26.90pp）、夏普 0.483 → **0.621**、费用 169,135 → **36,577 元**（−78.4%），8 个年度全部跑赢。

**这不是「加因子」带来的提升**：股东户数、两融都试过，没有一条通过预注册门槛；提升全部来自「不再为把权重拉回等权而付费」。

## 1. 与红利低波策略的唯一差异

| | 红利低波策略 | **红利低波增强策略** |
|---|---|---|
| 因子 | div_yield, vol_60, turnover_20, insider_net_20 | **完全相同** |
| 选股 | 月度、top50、等权、gross 0.95 | **同一份 weights 矩阵** |
| 执行 | 每个交易日都把权重拉回目标 | **只在调仓日成交**，其余日不动 |
| 实现 | `Engine`（逐日按 equity×w 重算目标） | `ShadowEngine(policy="monthly")` |

其余口径（池、剔除、`min_price=2.0`、`min_history=120`、退市 haircut30、成本、基准）与红利低波策略完全一致，见 `红利低波.md` §2。

## 3. 机制与代价

- **机制**：`Engine` 每天按 `equity × 目标权重 / 价格 / 整手` 重算目标股数；浮点误差与整手取整会让它每天卖掉一手、次日再买回，叠加 **5 元最低佣金**，把 8 年费用推高到 16.9 万。增强版只在调仓日下单，天然没有这个损耗。
- **代价**：月内不再向目标权重回归，实际暴露会随价格漂移（单票权重偏离目标）；在 A 股短期反转下，这种「不回归」在本策略上**是正收益**（与本策略相反的是小盘成长策略：那边逐日回归值 +3.5%/年）。这一点不可跨策略照搬，必须各自实测。
- **容量**：4,628 笔/8 年，单笔金额大，最低佣金的影响可忽略。

## 4. 使用边界

1. **不是独立策略**：与红利低波共用同一份选股，同涨同跌，**不能**用来做组合分散；保留两条是为「同一选股、两种执行」可对照、可回滚。
2. **样本外已被污染一次**：2025-01~2026-10 打开过一次（增强 +14.64% vs 现状 +12.64%），只能当方向参考；下一次真检验必须用 2026-10 之后的纸面/小资金，并重新封存。
3. **不要往上叠新因子**：`results/enhance-alternative`（等权并入 −5.97pp）与 `results/enhance-filter`（硬过滤/倾斜 −16 ~ −34pp，安慰剂净贡献 ±3pp）都已判定不通过。
4. **换手预算未在本策略验证**：buffer 2x + 单月换手上限 30% 在另一套因子上是 +6.6pp、费用再降 37%，但没有在红利低波上重跑；要用须单独预注册。
5. **仍然跑不赢纯红利**（174.36%）：差距来自选股，不在执行。
