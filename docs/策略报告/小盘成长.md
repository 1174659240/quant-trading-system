## 0. 一句话

在沪深两市里，先用「扣非盈利质量 + 成长加速度 + 合同负债」等基本面把公司筛成「真成长」，再按「成长 40% / 质量 25% / 研发 15% / 辅助 20%」合成打分，取前 50 只等权持有；月度调仓、次日开盘成交、单一证监会门类不超过 25%；额外挂一层只针对 2008 型系统性急跌的极端清仓开关。

样本内（2017–2024）年化 **9.48%**、夏普 **0.46**、最大回撤 **−31.85%**；同池等权基准同期年化 1.34%、回撤 −44.47%。holdout（2025-01~2026-10）年化 **21.50%**、夏普 1.12、回撤 −16.24%，但超额高度集中在 3 个月，且 2025 年几乎零超额。

## 1. 定位与预期

- **用途**：卫星仓。进攻、吃小盘成长的 beta + 一点选股 alpha，不承担「稳健替代理财」的角色。
- **预期**：长期中枢 **9–12%/年**（不是 20%）。依据：样本内 9.48%、拼接 9.78 年 11.49%、历史样本 18.07%（因子子集口径）、holdout 21.50%（1.8 年、小盘占优窗口）。
- **代价**：正常年份就会有 −20% 级别的年度亏损（2018 年 −19.65%），最大回撤 −31.85%；滚动 3 年有 79% 的时点 ≥9%，最差 3 年 −0.84%，最差单年 −31.2%（滚动 1 年口径）。
- **零杠杆**、不做空、不碰衍生品；不追求低回撤，只用风控层压「系统性急跌」。

## 2. 策略定义（冻结）

### 2.1 股票池与交易约束

| 项 | 取值 |
|---|---|
| 池 | 沪深两市（**不含北交所**、不含 B 股） |
| 剔除（R1–R9） | ST/*ST、上市不足 365 天、停牌（volume≤0）、一字板（\|high−low\|≤close×1e-4 且 \|close/prev_close−1\|≥9.5%）、退市整理期（退市前 45 自然日）、扣非 TTM ≤ 0、商誉/归母净资产 > 30%、资产负债率 > 70%（金融业整体剔）、经营现金流与扣非背离（OCF/扣非<0 或 (扣非−OCF)/总资产<−0.10）、非经常性损益占 \|归母\| > 50% |
| 市值地板 R10 | **默认不启用**（消融显示剔除最小 30% 会伤害收益） |
| 成交 | 信号在月末收盘生成，次月首个交易日**开盘**成交；整手 100 股；T+1；涨跌停不可成交 |
| 单票参与率 | ≤ 当日成交额 10%；单笔 < 5,000 元的订单忽略 |
| 退市 | haircut30（按最后交易日价格折价 30% 变现） |

### 2.2 因子（QN 十因子，事前登记，看到 IC 后只删不增）

| 块 | 权重 | 因子 | 方向 | 口径要点 |
|---|---|---|---|---|
| 成长 | 40%（2×20%） | `g4_eav` 盈余加速 | + | 单季扣非/总资产 的同比变化再取一阶差（EAV 口径，避免负基数爆炸） |
| | | `e1_contract_yoy` 合同负债+预收款同比 | + | `CONTRACT_LIAB + ADVANCE_RECEIVABLES` 相加（2017 起，跨准则断层按剩余项归一） |
| 质量 | 25%（3×8.3%） | `g5_stability` 盈利稳定性 | − | 近 8 个单季 ROA 的标准差 |
| | | `g8_gm_yoy` 毛利率同比变化 | + | 单季自算 `(营收−成本)/营收` 的同比差，2021-03 起（此前报表格式不可比） |
| | | `g9_roic` ROIC | + | 数据湖 `indicator.ROIC` |
| 研发 | 15%（1×15%） | `e3_rd_delta` 研发强度变化 | + | TTM 研发/TTM 营收 的同比差，2018 起 |
| 辅助 | 20%（4×5%） | `a1_reversal` 短期反转 | + | −(60 日跳 5 日动量) |
| | | `a2_amihud` 非流动性 | + | \|收益\|/成交额 的 20 日均值 |
| | | `n8_unlock_60d` 未来 60 日解禁压力 | − | 解禁市值/流通市值，事件日历法 |
| | | `n9_unlock_120d` 未来 120 日解禁压力 | − | 同上 |

- 门槛（G3，只过滤不给权重）：最近 4 个单季里「扣非单季同比>0 且基期>0」至少 2 季。
- 已被删除（阶段 C 判定无效）：`g1_deduct_yoy`（扣非 TTM 同比，被门槛吸收，IC −0.002、t −0.28）、`e2_wc_gap`、`e6_nonrec`、`g6_rd_intensity`、`a3_small`（与 mcap 同源重复）。

### 2.3 打分与合成

1. 每个因子在**成长合格集内**做 1%/99% winsorize 后取 rank_pct（不是全市场排名）；
2. 块内等权平均，缺失因子在块内重归一；
3. 块间按 40/25/15/20 加权，整块缺失则按剩余块权重归一；
4. 分数越高越优先。

### 2.4 组合构造

- 持仓 **50 只**，等权，**gross 0.95**（留 5% 现金），单票上限 4%；
- **证监会门类上限 25%**（行业取 `ref/industry.csv` 年度 PIT 版本，按调仓日当时有效；实测 96/96 个月 binding，最大门类 26.0% gross）；
- **缓冲带 60**：已持仓股票只要仍在候选前 60 名就保留，只换掉跌出缓冲带的，新补按排名补到 50 只；
- 逐日向目标权重回归（不只在调仓日交易，实测这一条在 A 股短期反转下值 +3.5%/年）。

### 2.5 风控层 E（极端清仓，默认开启）

- **触发**（连续 3 个交易日）：指数 < MA200 **且** 250 日回撤 ≤ −20% **且** 广度（近 20 日跌幅 >10% 的股票占比… 取 breadth ≤ 12%）**且**（20 日收益 ≤ −35% **或** 60 日收益 ≤ −45%）。
- **企稳**：15 个交易日不创新低，且波动分位 < 0.97 或较段内峰值回落 ≥ 0.10。
- **回补**：按缺口 1/2 → 1/3 → 1/6 递减三档加回，每档间隔 ≥ 20 个交易日；趋势闸门（近 5 日新低 或 非流动性 >95% 分位且恶化）暂停加仓。
- 定位：**只管 2008 型快速深跌**。历史样本 2008 段把 −62.82% 压到 −56.03%；2015 型急跌+二次探底会小亏（−10.07% → −37.03%）；慢熊（2001–2005）、熔断（2016-01）、V 型浅跌（2020-03）零触发、不负责。
- **样本内与 holdout 均零触发**（等价无风控），所以这条规则在本策略上的实际保护从未被实盘检验。

### 2.6 成本模型

| 项 | 取值 |
|---|---|
| 佣金 | 双边万 2.5，**最低 5 元**（小单杀手：中位订单 1,029 元时 = 48bp） |
| 印花税 | 卖出 0.05% |
| 过户费 | 0.001% |
| 滑点 | **分档** 2/2.5/3/4/5bp，按月末 ADV20 + Amihud 事前定 5 档；实测加权 3.44bp |
| 往返合计 | 默认档约 14.2bp；保守档 30bp / 50bp 用于敏感性 |

## 3. 数据与 PIT

- 日线：`D:/quant-data/processed`（2016 年前仅预热）；退市股用 `delisted/daily` 并入，跨层只合并收益率。
- 财务：`fundamentals/{profit,balance,cashflow,indicator}`，**只用 `NOTICE_DATE ≤ t`** 的已披露值，公告日当天收盘生效；同比/TTM 两端对齐；`REPORT_CUTOFF` 硬编码（样本内 2024-12-31，holdout 单独放行）。
- 市值 = 收盘价 × `shares_at(day).total_share`（PIT 股本；禁用最新股本字段）。
- 补充数据：业绩预告/快报、限售解禁、股权质押（`D:/quant-data/alt`，自采，**止于 2024-12-31**）。
- 已知后视偏差：财务是「修订后值」；无 PIT 行业细分（只有门类）；`events` 层为修订值。

## 5. 稳健性与过拟合检验（阶段 4，主规格 v1）

| 检验 | 结果 | 判定 |
|---|---|---|
| 截面置换 1,000 次 | 真实 IC 0.0431，p=0.001 | ✅ |
| Walk-forward（滚动 36 月） | 5 个年度窗口 4 个为正 | ✅ |
| IS/OOS 落差 | 2017–2020 4.77% vs 2021–2024 14.38%（OOS 更好） | ✅ |
| Deflated Sharpe | N=4 → 0.591；N=38 → 0.188；N=327 → 0.050 | ❌ |
| PBO/CSCV | 0.655 | ❌ |
| Bootstrap（块长 6 月） | 夏普 95% 区间 [−0.13, 1.02] | ❌ |
| 参数敏感性 | 持仓数 30→70 只 CAGR 7.09%–9.58%（极差 2.5pp）；单票上限 3/4/5% 三行完全相同（**空参数**） | ⚠️ 部分 |

**综合可信度：中低。** 信号真实存在（置换 p=0.001、成长池内 IC 0.043），但强度很弱，且多重检验后不能拒绝「夏普=0」。

## 6. 已知缺陷与使用边界

1. **beta 很重**：样本内 beta 0.84、holdout 0.72；所谓 alpha 很大程度是「小盘 + 高换手 + 高波动 + 低价」这一簇的风格暴露（该簇 2017 年为负、2021–2023 爆发、2024 归零）。风格反转时它会跟着跌。
2. **换手 365%/年**，费用 0.44%/年；把换手压到 200% 的所有尝试（平滑、分批、软权重、成本感知）全部负和 → 已放弃该目标，改为「费用 ≤0.50%/年」。
3. **风控层未被检验**：E 层在样本内与 holdout 都零触发；只对 2008 型有效，慢熊/熔断/V 型浅跌不负责。
4. **holdout 超额集中**：3 个月贡献超过全部超额，2025 年零超额 → 不能把 21.5% 当常态。
5. **数据缺口**：另类数据止于 2024-12-31（holdout 期解禁因子为空）；2025+ 退市事件缺失（历史回测可能高估）。
6. **容量**：100 万本金单票 1.9 万，10% 参与率只需 ADV ≥ 19 万（余量约 200 倍）；1,000 万时最不流动那一档（ADV 中位 2,500 万）开始吃力。

**不要**：把它当稳健替代、加杠杆、拿 20% 当年化预期、据 holdout 结果改因子（会让验收作废）。
