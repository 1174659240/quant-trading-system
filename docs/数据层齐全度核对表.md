## 三、已冻结的口径（改这些等于改结论，必须走第四节流程）

1. **价量层截止 2024-12-31**：所有回测/因子结果的样本末端都是这一天，不是「今天」。
2. **复权方式**：在市用 `adjustflag=3`（不复权）+ `adj_factor`，退市股用 `adjustflag=1`（后复权）——两者不混用，
   跨层合并时只用收益率，不拼价格。
3. **universe 语义**：`is_delisted` 与 `is_pending_delist` 互斥；在途退市（`601059`/`601198`，`out_date 2026-10-19`）
   在基准日按「在市」处理。
4. **财务可用时点**：一律 `NOTICE_DATE`，缺失才 `+110 天`，绝不按报告期末直接对齐。
5. **行业归属**：历史一律用 baostock 年度 PIT，申万快照只做当期描述。
6. **市值口径**：`收盘价 × shares_at(day) 的 total_share`，禁用 `MAINFINADATA.TOTAL_SHARE`（它是最新股本，含未来信息）。
7. **退市处置**：`last` / `haircut30` / `total_loss` 三档必须并列，单报一档视为结论不完整。

## 四、变更流程（谁改谁登记）

1. 改任何一层：先跑 `python -m scripts.freeze_datalayer`，把新旧 JSON 的行数差写进 commit message；
2. 同步更新本表对应行的「文件 / 行数 / 覆盖 / 缺口」，以及 `docs/数据湖落地记录.md` 的对应小节；
3. `python -m quant doctor` 必须 0 失败；`tests/run_all.py` 必须全绿（当前 168 项）；
4. 偏差声明有增减时，同步 `docs/数据湖落地记录.md` 4.7（当前 13 条）。

## 五、15 条固定偏差声明（摘要）

1. 财务为**修订后值**，修订偏差不可回滚；
2. 可用时点用 `NOTICE_DATE`，不用报告期；
3. 行业为**年度** PIT，重组后可能滞后一年；
4. 申万行业只有当期快照；
5. 指数成分只有当期快照 → 幸存者偏差；
6. 退市收益按 CRSP 分层，`−30%` 与 `−100%` 双版本并列；
7. 估值/isST 为逐日快照回填，停牌日沿用最近有效值；
8. **北交所 351 只全区间无估值/财务** → 任何「全市场」结论读作「沪深两市」；
9. **2014 年前退市的 81 只无日线** → 该段幸存者偏差非零但量级较小；
10. **分红只用已实施（`ex_date`）**：`div_yield` 不含预案期，等于「公告后才知道」，会系统性地低估「预案已知就能买」的可交易性；
11. **换手宽表与估值层同源**：`turn` 为 baostock 当日换手率，停牌日缺失、北交所整体缺失；
12. **事件层为免费接口 + 修订后值**：回购「最新公告日期」每次进度更新会覆盖旧值，增减持按「变动日 +2 交易日」近似可见日，均偏乐观；
13. **龙虎榜 `post_1d..post_10d` 是接口自带的未来收益**，只留在表里做研究展示，**未进入任何因子**；ST 翻转仅 1,353 次，`st_flag_20` 在 95 个月里只有 1 个月有横截面方差 → 不可用。

## 七、复现命令

```powershell
python -m quant lake ref --what universe,industry,shares,sw   # 参考数据四块
python -m quant lake dividends --start 2013-12-31 --end 2024-12-31   # PIT 分红（约 32 秒）
python -m quant lake turnpanel --cutoff 2024-12-31            # 换手宽表（约 10 秒）
python -m quant lake events --what all                        # 事件层六表（约 4 分钟；2025+ 只落盘不读取）
python -m quant lake valuation --shard 0/4 --start 2014-01-01 # 估值/isST（4 片并行，约 6 小时）
python -m quant lake fund                                     # 财务三表 + 指标表（约 21 分钟）
python -m quant lake mainfin                                  # 指标表投影（1.6 秒）
python -m quant lake index                                    # 指数成分
python -m quant lake delisted                                 # 退市股日线 + 事件表（约 49 分钟）
python -m scripts.freeze_datalayer                            # 生成核对指纹（样本内）
python -m scripts.freeze_datalayer --include-holdout          # 附带 holdout 层统计
python -m quant lake valuation --holdout --shard 0/4          # holdout 估值（4 片并行，约 50 分钟）
python -m quant lake dividends --holdout                      # holdout 分红（7 期）
python -m scripts.holdout_validation                          # 一次性验收（约 2 分钟）
```
