## 2. 入场：左侧分批回场（本次新增）

### 2.1 开始分批的四个条件（必须同时满足）

| 编号 | 条件 | 阈值 |
|---|---|---|
| C1 | 危机分从**本段滚动峰值**回落 | ≥ 0.20（峰值用段内 cummax，**不用整段最高分**，避免未来信息） |
| C2 | 最近 N 个交易日不再创新低 | N = 15；新低定义：当日收盘 ≤ 过去 15 日最低 |
| C3 | 波动率已从极端分位回落 | `vol_pct < 0.97` 且（本段滚动 vol 峰值 < 0.90 或 `vol_pct ≤ 滚动峰值 − 0.10`）；`vol_pct` = 指数 20 日已实现波动在**过去 500 日**内的分位 |
| C4 | 从本轮高点累计跌幅已进入「下半场」 | ≤ **−20%**（指数 / 过去 500 日滚动最高价 − 1） |

### 2.2 趋势闸门（暂停加仓，不清仓）

| 编号 | 暂停条件 | 恢复条件 |
|---|---|---|
| G1 | 最近 **5** 个交易日内出现新低（收盘 ≤ 过去 15 日最低） | C2 重新满足（连续 15 日无新低） |
| G2 | 市场非流动性恶化：`illiq_pct > 0.95` 且 `illiq_20 > illiq_20.shift(20)` | `illiq_pct ≤ 0.95` 或不再恶化 |

`illiq_20` = 个股 `|日收益| / 成交额` 的截面等权均值再做 20 日均值；`illiq_pct` 为其过去 250 日分位。

### 2.3 分批节奏

- 每次加回**剩余缺口到满仓的 1/3**：`exposure += (1 − exposure) / 3`。
- 两次加仓间隔 **≥ 20 个交易日**（约一个月）。
- 最多 3 次加满；任何一次加仓都受 G1/G2 闸门约束。
- 危机状态结束（`state=False`）后，若仍有缺口，按 10 个交易日线性回补到 1.0。
- 加仓只在**月频调仓日**生效（与主策略同频，避免把月频策略变成日频交易）；判定条件逐日更新，但执行日只在月末调仓日。

## 3. 阈值标定依据（主样本 2017-01~2024-12，只用于选 C4）

| 统计 | 值 |
|---|---|
| 危机段数 / 危机天数 | 14 段 / 614 天 |
| 危机日回撤中位 | −21.6%（p25 −31.9%，p75 −16.9%） |
| 各段低谷回撤分布 | −16.7% ~ −47.2%，中位 −22.6% |
| 分数从峰值回落 0.2 当日的回撤 | −14.1% ~ −33.1% |

结论：`C4 = −20%` 约等于「跌破危机日回撤中位」，即下跌下半场；在该阈值下主样本 14 段中有 2 段（2018-03-15、2024-08-14）会启动分批，
`C4 = −15%` 触发 7 段、`C4 = −25%` 只触发 1 段。

**事前声明**：主规格固定 `C4 = −20%`；`−15%` 与 `−25%` 作为**事前的敏感性对照**一并跑，但**不得**用它们的结果替换主规格。
