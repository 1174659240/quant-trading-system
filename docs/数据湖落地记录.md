## 二、口径（写死在代码里）

1. **不复权入库，复权后算**：`build_factor_index` 用分红送转事件算前复权缩放因子
   `k = (P0 − 现金红利) / (1 + 送股) / P0`，按除权日连乘；`apply_qfq` 把 OHLC 乘上 `k`，另存 `adj_factor` 列；
   成交量/成交额不下调，原始层 `close` 始终是真实现金价。
2. **停牌显式入库**：按交易日历 reindex，缺失交易日填 `suspended=1`、`volume=0`、`amount=0`、OHLC=前收，
   只在「上市首日 ~ 最新日」之间补，不凭空造上市前行情。
3. **校核集加锁**：`holdout/daily/` 默认不可读，调参/选因子只允许碰 `processed/`，避免样本内挑参。

## 三、过程中的坑（下次直接绕开）

- **行情源已大改（2026-10）**：东财 `push2his` 间歇性 `RemoteDisconnected`（整段 IP 级限流）；腾讯 `fqkline`（带复权）已 501 下线，
  只剩 `kline`（不复权、单页 640 根、需翻页）；新浪单只上限 1023 根（约 4 年）；北交所腾讯只回 1 根、必须走新浪。
  `Lake.source_for` 已固化：北交所 92/43/83/87 段自动切新浪，其余走腾讯、失败再兜底新浪/东财。
- **抓取必须分片可续跑**：5576 只全量约 1.5 小时（~1/s）。`manifest.json` 被多进程同时写会互相覆盖（`JSONDecodeError`），
  已改成每进程写独立 tmp 再合并。
- **`apply_qfq` 性能坑**：旧实现按事件逐条扫全表，单只 15 秒（38k 条事件 × 2.6k 行），split 5575 只要 9 小时；
  按 symbol 分组 + `searchsorted` 前缀积后单只 ~2ms，全量 split 75 秒。等价性已用 5 只票逐位对拍（maxdiff 3e-16）。
- **PowerShell 5.1 读写中文文件**：`Set-Content`/`Get-Content -Raw` 会破坏 UTF-8（曾把 README 写成乱码），
  一律用 Python 读写（`encoding="utf-8"`）。
