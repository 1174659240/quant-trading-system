# 稳健改进三项：预注册（运行前冻结）

日期：2026-10-22 ｜ 冻结时点：任何回测运行之前 ｜ 样本：2017-01-03 ~ 2024-12-31
基线：**cap 25% 版**（QN 合成、缓冲带 60、逐日向目标权重回归且忽略 <5000 元单、分档滑点 tier1–5、E 极端清仓层默认开、50 只、gross 0.95、单票 4%、门类上限 25%）
基线数字：累计 105.63%、CAGR 9.475%、夏普 0.4595、MDD −31.85%、卡玛 0.2975、单边年换手 365.5%

**总判据（三项统一）**：**MDD 改善 ≥3.00pp 且夏普不下降**（夏普允许 −0.000 的浮点误差）。不达标即"不采用"，不回改规则。
**附加要求**：任何一项若同时让换手上升 >50pp，或让 CAGR 下降 >1.00pp，须在结论里单独标注代价。

## 一、vol target 18%

### 1.1 规则（写死）

| 项 | 定义 |
|---|---|
| 波动估计量 | 策略**自身**日频净值收益的 20 个交易日滚动标准差 × √244（年化），只用 `t−1` 及以前的数据 |
| 缩放公式 | `scale_t = clip(0.18 / σ_{t−1}, 0, 1.0)`；**只降不升**（上限 1.0，不加杠杆、不加仓） |
| 最小样本 | 滚动窗口不足 20 日时 `scale=1.0` |
| 平滑 | **不做**（无滞回、无移动平均） |
| 生效方式 | 每日把目标权重整体乘以 `scale_t`，差额留现金；不做行业/个股权重再归一 |
| 成本 | 与基线完全相同（分档滑点 + 5 元最低佣金 + 印花税） |

### 1.2 为什么是 18%

基线实现波动约 19.6%（`stats_block` 的 `vol`），25% 目标在样本内 8 年只触发 12 天（均值 0.983）→ 从未真正检验。18% 略低于实现波动，预计在 20–30% 的交易日 binding。**这是事先论证，不是从结果反推**。

### 1.3 判据

MDD 改善 ≥3pp 且夏普不降。若只改善 MDD、夏普下降，则**不采用**（与阶段 5 的清仓结论一致口径）。

## 二、流动性尾部剔除

### 2.1 规则（写死）

在**每个调仓日**（月末），对成长合格集内的股票，同时施加两条剔除（数据只用 ≤ 当日）：

1. **ADV 尾部**：过去 20 个交易日成交额均值（`amount` 均值）在合格集截面中处于**最低 5%**（`rank(pct) <= 0.05`）→ 剔除；
2. **一字跌停尾部**：过去 250 个交易日内出现 **≥2 次"一字跌停"** → 剔除。
   "一字跌停"定义：`high == low` 且 `close/prev_close − 1 <= −0.095`（主板）；创业板 2020-08-24 起、科创板 2019-07-22 起用 `<= −0.19`。

剔除后不再补足到 50 只（保持"选不满就留现金"，与基线一致）。股票池、因子、权重、成本全部不变。

### 2.2 为什么是 5% / 2 次

- 流动性：阶段 0 实测低流动性组（后 1/3）中位 ADV 3,765 万；50 只 × gross 0.95 时单票 1.9%，100 万本金下单 1.9 万，占 ADV 0.05%——**容量不是问题，卖不掉才是**。取 5% 是"只切最尾部"，避免动到主要收益来源（低流动性溢价）。
- 一字跌停：8 年内 ≥3 天的只有 194 只（3.7%），≥2 次是"曾经被锁死过"的最低门槛，属于"流动性已经出过问题"的事前标记。

### 2.3 判据

MDD 改善 ≥3pp 且夏普不降。
**必须同时报告反事实**：被剔除组在随后一个月的等权收益，用于判断是否误杀 alpha（若被剔除组显著跑赢，说明在砍收益）。

### 3.1 规则

逐个删除下列因子（从各自所在块中移除，块内按剩余因子重新等权平均，跨块权重 40/25/15/20 不变，缺失块按剩余块归一）：

|---|---|---|---|
| 目标 1 | `g5_stability` | 质量（5 项） | IC +0.0145、t 1.98 |

| 目标 4 | `e6_nonrec` | 质量（5 项） | IC −0.0034、t −0.49 |

### 3.2 判据

- 删除后 CAGR 变化在 **±0.20pp** 以内 → 确认可精简（保留删除）；
- 若 CAGR 下降 >0.20pp 或 MDD 恶化 >1pp → 保留该因子并说明；
- **不因删除而重新调整其他参数**（块权重、持仓数、缓冲带一律不动）。
