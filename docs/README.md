## 7. 三条不变纪律

1. **holdout（2025-01-01 起）只能一次性使用**。小盘成长的额度已用掉（2026-10-16），红利两条的额度也已被打开过一次；再要检验只能向前看，见 `docs/策略报告/小盘成长.md` §6。
2. **看到结果后只能删，不能加**。改因子、改参数、改阈值 = 新版本，旧报告的样本外结论作废，须重新登记、重跑、升版本号。
3. **数字必须可复算**。每份结论文档都带复现命令；引用数字时给出「哪个脚本 + 哪个结果文件」，不凭记忆。
