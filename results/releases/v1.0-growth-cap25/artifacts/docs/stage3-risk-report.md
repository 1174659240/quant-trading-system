## 6. 口径

- 单边换手 = 成交额 / 2 / 平均净值 / 年数（成交口径，含被最小成交额过滤掉的尝试之外的全部成交）。
- 加权滑点 = 滑点成本合计 / 成交额合计。分档滑点按「ADV20 分位 + Amihud 分位」合成流动性分数，最好档 2bp、最差档 5bp，档位在每月末事先确定。
- 费用/净值·年 = 累计费用 / 平均净值 / 年数。
- 平均暴露 = 逐日 gross_exposure 均值；清仓方案的空仓天数见 risk.json 的 cash_days。
- 真实 Engine（含佣金最低 5 元、印花税、过户费、整手、涨跌停、10% 参与率、退市 haircut30）；2025-01-01 之后的数据未读。
