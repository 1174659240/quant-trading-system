# 阶段 4.5：软权重 + 成本感知再平衡 —— 稳健性对比

生成：2026-10-21 ｜ 主样本 2017-01-04 ~ 2024-12-31（1,942 个交易日）｜ 历史样本 2008-01-03 ~ 2016-12-30（2,189 个交易日）
本轮只读 2016 年底之前与 2017–2024 的数据；**2025-01-01 起 holdout 未读取**。旧版本与旧结果目录原样保留。

## 0. 一句话结论

**两处改造都没有解决「单边年换手约 4 倍」这个结构性问题，因此不建议替换旧版。**
软权重（top40/50/60 平均）把换手从 395% 抬到 **438%**，收益只多 0.24pp、回撤恶化 1.6pp；成本感知再平衡在软权重之上几乎不生效（跳过 1,414 万个「日×票」组合、只成交 5,186 个，触发带中位数仅 0.14% 权重），换手 438% → **437.5%**。
七项检验的通过/不通过结构**与旧版完全同构**（置换、WFA、IS/OOS 通过；DSR、PBO、Bootstrap、参数敏感性不通过）。

## 1. 检验对象与口径

| 规格 | 定义 |
|---|---|
| **v1 legacy5k_slip**（旧版，对照） | QN 合成 + BufferTopK(50, 缓冲 60) + 逐日交易、忽略 <5,000 元订单 + 分档滑点 + **E 极端清仓层** |
| **v2a** | 同上，但选股改为 **SoftTopK**：调仓日分别算 top40/50/60，取三者平均权重（边界平滑），**无缓冲带**；无成本感知 |
| **v2b** | v2a + **成本感知再平衡**（逐日判断「偏离的跟踪误差收益 vs 交易成本」） |

共同口径：成长合格集、行业门类上限 30%、gross 95%、单票上限 4%、月频调仓日、t+1 开盘成交、真实 Engine（佣金/印花税/过户费/涨跌停/退市 haircut）、分档滑点 tier1–5 = 2.0/2.5/3.0/4.0/5.0bp。

## 3. 为什么换手没降下来（换手解剖）

**(1) 换手不是「每天小幅漂移」，而是「每个调仓日整体换池」。**
旧版 `trades-legacy5k_slip.csv` 共 4,438 笔成交，其中 **2024-11-01 单日 84 笔、金额 3.09M ≈ 当日净值 155%**；相邻两月持仓重叠率均值 **0.679**、中位 0.840，但 **22% 的月份重叠率 <0.30**（几乎整池换掉）。换手集中在少数几个「打分剧烈翻转」的月末。

**(2) 成本感知的触发带比换池幅度小一个数量级。**
判据 `|Δw| > 2·c·TE / (h·σ²)`：
- `c` = 佣金 2.5bp + 过户费 0.1bp + 分档滑点（当日档位，年化中位 3.44bp）+ 卖出印花税 5bp；
- `TE` = 当期偏离的年化跟踪误差（对角近似），`h = 1/12` 年，`σ` 用 250 日已实现波动。

实测 **band 中位数 = 0.14% 权重**；而换池一次的单票权重变化是 **1.9%**（= 0.95/50）→ 相差约 **13 倍**，只要目标变了就通过判据，等于没拦。
日志：`成本感知：跳过 14,142,826 个(日,票)，成交 5,186 个`——被跳过的那 1,414 万个里绝大多数本来 `Δw = 0`（没有目标变化），**真正被拦下的边际交易极少**。

**(3) 软权重本身把缓冲带丢了。**
v1 的缓冲带 60 是换手的主要闸门（阶段 3.1：无缓冲 428% → 缓冲 60 为 395%）。v2 按任务要求只做「三套权重平均」，没有缓冲带，于是回到 ~438%。**软权重替代不了缓冲带**：它平滑的是「第 50 名/第 51 名」的边界，而换手来自「前 40 名整体被替换」。

## 6. 副产品（对后续有用，但不改本轮结论）

1. **行业门类上限是真成本**：取消 30% 上限，CAGR 9.78% → 11.37%（+1.59pp）、夏普 0.463 → 0.516。成长池里行业集中（电子/医药/机械）本来就是要吃的 beta，强行压到 30% 会削收益。这是事前规则，本轮不动，但值得下一轮正式消融。
2. **最低佣金仍是最大单项成本**：最低订单 0 元 → CAGR 8.37%（−1.4pp）、费用 2.02%/年；10,000 元 → 8.65%。5,000 元过滤处在合理区间（8.37% 与 8.65% 之间偏优）。
3. **分档滑点不是主要成本**：固定 2bp vs 分档 → 9.91% vs 9.78%，差 0.13pp/年。

## 7. 结论与建议

| 判断 | 结论 |
|---|---|
| 软权重是否值得替换旧版？ | **否**（收益 +0.24pp 换不来换手 +43pp、回撤 −1.6pp） |
| 成本感知是否值得保留？ | **否**（对换手几乎无影响：438%→437.5%） |
| 七项检验是否更稳？ | **否**（通过/不通过结构与旧版同构，DSR 因 N 增加略降） |
| 建议主规格 | **保留 v1 `legacy5k_slip`**；v2 作为「已证伪的替代方案」记录在案 |

**下一步该往哪打**：换手的根因在「打分本身的月度稳定性」（重叠率 22% 的月份 <0.30），不在交易层。可试的方向（本轮未做，需另起预注册）：
- 打分的时序平滑（对因子得分做 2–3 个月移动平均，而非对权重做缓冲）；
- 分批建仓/分批撤出（把一次换池拆成 2–3 个月执行）；
- 降低调仓频率到季频 + 更宽的缓冲带。

## 10. 局限（必须与结论一起读）

1. **PBO 未真正纳入 v2 配置**：`pbo_cscv` 的配置矩阵仍来自阶段 4 的 21 个候选（v2 的软权重变体没进矩阵），所以 0.655 是「原候选族」的 PBO，不是 v2 的。要算 v2 的 PBO 需要把 v2 的多个邻域点纳入矩阵，成本约 7–10 次回测（本轮未做）。
2. **置换检验用的是同一套 QN 打分**（v2 只改权重构造，不改打分），所以 p=0.001 与阶段 4 一致是预期结果，不是独立证据。
3. **历史样本 v2 未接 E 层**（见 §5 口径警告）。
4. **软权重无缓冲带**：v2 不是「缓冲带 + 软权重」，两者未联合测试，不能排除「缓冲带 + 软权重」会有不同结果。
5. 成本感知判据用对角近似跟踪误差、`h=1/12` 固定，未做参数敏感性（按任务要求「不引入需标定的自由参数」，但也因此无法证明它在该参数下最优）。
