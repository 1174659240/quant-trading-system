# 小盘成长策略：holdout 一次性样本外验收（2025-01-02 ~ 2026-10-16）

> **一次性、不可回调**：本报告是冻结口径（cap25）在 holdout 层上的唯一一次正式验收。
> 结果不用于修改因子、参数或规则；若未来改动策略，本报告即失效，需另行登记新的验收。

## 0. 结论（客观陈述）

- 策略累计 **+41.06%**、年化 **+21.50%**、夏普 **1.118**、最大回撤 **-16.24%**（2026-07-17）。
- 同期同池等权基准累计 +26.92%、年化 +14.45%、夏普 0.652、最大回撤 -20.69%。
- 相对同池等权的年化超额 **+7.05%**，累计超额 +14.13%。
- 单边年换手 393%，费用占净值 0.48%/年，加权滑点 3.57bp，成交 1067 笔。
- E 层（极端清仓）在窗口内**触发 0 次**，平均仓位 1.000 → 本期收益完全来自选股与组合构造，风险层未被检验。
- 月胜率（相对同池等权）10/22 = 45%。
- **读法**：本期未被证伪，但超额高度集中在 2026-01/03/07 三个月（合计 +21.02%，其余月份合计为负），2025 年（同池 +34.8%）几乎零超额；beta 0.718。因此数字支持「策略在样本外没有崩」，不支持「超额稳定可复制」。

### 4.1 超额集中度体检（诚实读法的前提）

- 月度超额之和 +10.09%，正超额月份 10/22。
- 最大的 3 个月超额（2026-07, 2026-03, 2026-01）= +11.61% / +5.21% / +4.19%，合计 +21.02%，占月度超额之和的 208%（超过 100% 是因为其余月份合计为负）。
- 日频 beta（vs 同池等权）**0.718**、相关系数 0.893。
- 读法：超额高度集中在少数月份（尤其 2026-07），2025 年几乎没有超额；因此本报告支持「策略没有被样本外证伪」，不支持「超额稳定可复制」。

## 7. 已知数据缺口与处理（如实声明）

1. **另类数据止于 2024-12-31**：解禁 n8/n9 在 holdout 期为空 → 辅助块按剩余 a1/a2 归一。
   这使 holdout 期的 aux 块与样本内不同构，是**已知偏差**，不是策略改动。
2. **2025+ 退市事件缺失**：`delisted/events.csv` 只到 2024；holdout 期若有股票退市，
   引擎按最后可用价格持有，未做折价处理 → 可能**高估**收益。
3. **ST 过滤**用 holdout 估值层的 `isST` 补齐；停牌/一字板沿用价量层掩码。
4. 财务用 `NOTICE_DATE ≤ 当日` 的最新一期（含 2025–2026 报告期），按披露日生效，无前视。
5. 行业为 PIT 门类（`ref/industry.csv` 年度版本，最新一版 2026-10-12）。
